ElectroShip - Simulador didáctico básico (12/24V DC)

📖 Guía rápida - Simulador Náutico

Bienvenido

Este simulador permite construir circuitos DC (12/24V) con componentes básicos. Arrastra elementos desde la paleta al área de trabajo y conéctalos haciendo clic en los conectores.

Usa Encender / Simular para ejecutar la simulación (solver nodal). Activa Modo falla para permitir que fusibles se quemen cuando la corriente exceda el umbral.

Componentes

  • Batería: Fuente DC (12V por defecto).
  • Resistor / Bombilla / Motor: cargas con resistencia.
  • Interruptor: doble clic para abrir/cerrar.
  • Fusible: doble clic para simular quemado (o quema automática en modo falla).
  • Voltímetro / Amperímetro: medidores colocables que muestran lecturas tras simular.

Cómo usar

  1. Arrastra una batería y una carga al tablero.
  2. Conecta los conectores con cables (clic en un conector, luego en otro).
  3. Coloca medidores si deseas ver voltajes o corrientes.
  4. Haz clic en Encender / Simular para ver lecturas y estados.

Consejo: si el circuito está abierto o hay un cortocircuito, la simulación mostrará un mensaje explicativo.
